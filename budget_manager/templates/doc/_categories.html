{{ _('Categories') }}

{{ _('Categories are the backbone of the application: they define how each transaction is classified and how budgets and statistics are computed.') }}

{{ _('Category types') }}

{{ _('Every category belongs to exactly one of the following types, which directly drive the behavior of dashboards and analytics:') }}

  • {{ _('INCOMES (type 0)') }} – {{ _('sources of money such as salaries, refunds or bonuses. Transactions in these categories are expected to have positive amounts and feed the income section of the home dashboard.') }}
  • {{ _('FIXED EXPENSES (type 1)') }} – {{ _('recurring, predictable charges like rent, utilities or subscriptions. They are used in the FIXED EXPENSES block and participate in the “Remaining for variable expenses” calculation.') }}
  • {{ _('VARIABLE EXPENSES (type 2)') }} – {{ _('flexible spending such as groceries, hobbies or transport. They appear in the VARIABLE EXPENSES block and in analytics for growing/falling categories.') }}

{{ _('Category list') }}

{{ _('The Category management page lists all categories with their main properties and quick actions:') }}

  • {{ _('Name and icon') }} – {{ _('the human‑readable name of the category and an optional emoji/icon, also displayed in transaction tables and analytics.') }}
  • {{ _('Color') }} – {{ _('used for visualizations such as donut charts; each category can have its own color tag.') }}
  • {{ _('Type badge') }} – {{ _('a colored badge indicating whether the category is an income, fixed expense or variable expense.') }}
  • {{ _('Calculated budget') }} – {{ _('if a monthly budget is configured, this column shows the amount in euros for the current month, derived from your total earnings.') }}
  • {{ _('Delete protection') }} – {{ _('some categories are not deletable (for example when they are structurally required or already used extensively). Non‑deletable categories show a “forbidden” icon instead of a trash icon.') }}

{{ _('Adding a category') }}

{{ _('When you create a new category you define both its visual identity and its financial role.') }}

  • {{ _('Name') }} – {{ _('short label that will be reused in all screens (home, transactions, analytics, savings).') }}
  • {{ _('Type') }} – {{ _('choose INCOMES, FIXED EXPENSES or VARIABLE EXPENSES depending on the behavior you expect on dashboards and budgets.') }}
  • {{ _('Color and icon') }} – {{ _('optional fields to make the category immediately recognizable in tables and charts.') }}
  • {{ _('Budget (for expenses)') }} – {{ _('for FIXED or VARIABLE EXPENSES you can optionally set a monthly budget as a percentage of your total earnings.') }} {{ _('Internally the application stores this percentage and multiplies it by the current eligible income to obtain a euro amount every month.') }}

{{ _('Once saved, the category becomes available in the transaction forms and will be taken into account in all subsequent calculations.') }}

{{ _('Editing a category') }}

{{ _('Editing allows you to rename categories, change their color or icon, adjust their type and fine‑tune their budget.') }}

  • {{ _('Updating the budget') }} – {{ _('you can increase or decrease the percentage to adapt to new income levels. Setting the budget to zero (or leaving it empty) removes the associated monthly budget for that category.') }}
  • {{ _('Changing type carefully') }} – {{ _('switching a category from income to expense (or the opposite) changes how its transactions are interpreted in all dashboards, so it should only be done when you fully understand the impact.') }}

{{ _('Deleting a category') }}

{{ _('A category can be deleted only when the application considers it safe to do so (for example if it is not used by critical internal logic).') }} {{ _('When deletion is allowed, clicking the red trash icon removes the category and its associated budget configuration; existing transactions should be cleaned up or reassigned beforehand to keep your data meaningful.') }}

{{ _('Categories in dashboards and analytics') }}

  • {{ _('The Home dashboard groups amounts by category type to build the INCOME, FIXED EXPENSES and VARIABLE EXPENSES tables.') }}
  • {{ _('Budget usage progress bars for fixed and variable expenses depend on the monthly budgets defined on categories.') }}
  • {{ _('Analytics use categories to detect top growing and top falling spending areas over configurable time windows.') }}
