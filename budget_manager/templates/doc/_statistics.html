{{ _('Statistics and analytics') }}

{{ _('The Analytics dashboard aggregates several views to help you understand how your balance, incomes, expenses and savings evolve over time.') }}

{{ _('Time window configuration') }}

{{ _('At the top of the Analytics page you can choose a number of months to analyze. This window drives all subsequent statistics: balances, incomes, leftovers and category trends are computed for the same period.') }} {{ _('The application validates this window (for example between 1 and 24 months) to avoid excessively heavy queries.') }}

{{ _('Balance evolution metrics') }}

  • {{ _('Current balance') }} – {{ _('the first card shows the current global balance, computed from all non‑excluded transactions.') }}
  • {{ _('Reference balance') }} – {{ _('a reference value is computed at the end of a past period (for example the balance N months ago); this allows direct comparison with the present.') }}
  • {{ _('Percentage change') }} – {{ _('the card displays the relative change between the current balance and the reference, with an up or down arrow depending on the direction of the evolution.') }}

{{ _('Income over the period') }}

{{ _('The second card focuses purely on incomes for the selected window, independently from expenses.') }}

  • {{ _('Current income') }} – {{ _('sum of all positive transactions in income categories across the current analysis window.') }}
  • {{ _('Reference income') }} – {{ _('sum of incomes in an equivalent previous period, so that you can compare, for example, the last 6 months of income with the 6 months before that.') }}
  • {{ _('Income change') }} – {{ _('percentage comparison between current and previous income, with visual cues to highlight increases or decreases.') }}

{{ _('Leftover and savings insights') }}

{{ _('The analytics module also computes, for each past month, how much money was left for saving after expenses and leverages this information to build savings insights.') }}

  • {{ _('Monthly leftover values') }} – {{ _('for each of the analyzed months, the system calculates a “leftover for savings” value by combining incomes, fixed expenses and variable expenses linked to the general buffer saving.') }}
  • {{ _('Average and median leftover') }} – {{ _('these statistics summarize how much you typically manage to save each month, smoothing out exceptional peaks or dips.') }}
  • {{ _('Savings insights per envelope') }} – {{ _('for every saving, the dashboard shows its current amount, goal, ratio, an evolution sparkline and an estimate of how much it can receive each month based on the median leftover and its ratio.') }}
  • {{ _('Estimated time to goal') }} – {{ _('when a goal and a positive expected monthly allocation are available, the system estimates in how many months the goal could be reached and displays an approximate target date.') }}

{{ _('Category spending trends') }}

{{ _('To identify which parts of your budget are drifting, analytics compares spending in expense categories between the current window and an equivalent past window.') }}

  • {{ _('Per‑category totals and medians') }} – {{ _('for each FIXED or VARIABLE EXPENSES category, the system gathers all monthly transaction amounts and computes both totals and a median typical spending value.') }}
  • {{ _('Growth rate') }} – {{ _('the percentage change in total spending for each category between the two periods is calculated to show where costs are accelerating or decreasing.') }}
  • {{ _('Impact score') }} – {{ _('by combining growth and median spending, analytics derives an impact score used to order categories by importance of their change.') }}
  • {{ _('Top growing and top falling categories') }} – {{ _('two lists present categories where spending is increasing the most and decreasing the most, helping you quickly spot budget leaks or successful optimizations.') }}

{{ _('Historical spending overview chart') }}

{{ _('At the bottom of the analytics page, a historical stacked chart summarizes spending and income trends over time.') }} {{ _('The chart uses color coding (for example green for income and another color for overall balance) so that you can visually follow how your situation evolves month after month.') }}
