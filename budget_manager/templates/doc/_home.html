{{ _('Home dashboard') }}

{{ _('The home dashboard gives a compact monthly overview of your financial health: incomes, fixed expenses, variable expenses and what is left for savings.') }}

{{ _('Period and scope') }}

{{ _('All amounts shown on the home page are computed for the current calendar month and for all transactions recorded in that period.') }} {{ _('The date of each transaction is taken into account, so back‑dating or correcting a transaction immediately updates the dashboard.') }}

{{ _('INCOMES block') }}

  • {{ _('Per‑category income') }} – {{ _('each row in the INCOME table corresponds to a category of type 0 (INCOMES).') }} {{ _('The “Monthly total” column sums all transactions of that category for the current month.') }}
  • {{ _('Total incomes') }} – {{ _('the bottom TOTAL row aggregates all income categories and is the reference used by other calculations (budgets, remaining amounts, analytics).') }}

{{ _('FIXED EXPENSES block') }}

{{ _('Fixed expenses are recurring, predictable costs such as rent, insurance or subscriptions. They correspond to categories of type 1.') }}

  • {{ _('Monthly total per category') }} – {{ _('each row shows the sum of all transactions for that fixed‑expense category in the current month. Negative amounts (expenses) are displayed in red for quick scanning.') }}
  • {{ _('Budget usage progress bar') }} – {{ _('for categories that have a monthly budget configured, a colored progress bar shows how much of the planned budget has already been consumed.') }} {{ _('The color adapts to the usage level: green for comfortable usage, orange when the consumption is high, and red when almost or fully consumed.') }}
  • {{ _('Fixed expenses TOTAL') }} – {{ _('the TOTAL row aggregates the monthly totals of all fixed‑expense categories and displays the overall budget usage percentage across these categories.') }} {{ _('A warning icon appears when the global percentage exceeds a critical threshold (for example 99%).') }}

{{ _('Remaining for variable expenses') }}

{{ _('Below the fixed‑expenses table, a dedicated line “Remaining for variable expenses” shows how much money is still available for day‑to‑day, non‑recurring spending after all fixed charges are taken into account.') }} {{ _('This amount is computed from your incomes and fixed expenses and acts as a real‑time envelope for VARIABLE EXPENSES. A warning icon highlights when the remaining amount drops below a small threshold (for example 20 €).') }}

{{ _('VARIABLE EXPENSES block') }}

{{ _('Variable expenses correspond to categories of type 2 and represent flexible spending such as food, shopping or leisure.') }}

  • {{ _('Monthly total per category') }} – {{ _('each row shows the monthly total of transactions for the corresponding variable‑expense category, with the same color conventions as for fixed expenses.') }}
  • {{ _('Budget usage') }} – {{ _('when a budget is configured on a variable category, the progress bar indicates how fast this budget is being used during the month.') }} {{ _('The global TOTAL row aggregates these usages into a single percentage for all variable expenses combined.') }}

{{ _('Remaining for savings') }}

{{ _('At the bottom of the VARIABLE EXPENSES column, the “Remaining for savings” line answers a key question: how much of this month’s income is still available once both fixed and variable expenses are included?') }} {{ _('This amount is closely tied to the Savings module: it is the basis for “leftover for savings” computations and for monthly distributions between individual savings accounts.') }} {{ _('A low remaining amount is highlighted with a warning icon so you can quickly detect months where expenses are about to overrun your capacity to save.') }}

{{ _('From dashboard to categories and budgets') }}

{{ _('The dashboard itself is read‑only, but every figure is derived from your categories and budgets:') }}

  • {{ _('INCOMES, FIXED EXPENSES and VARIABLE EXPENSES come from categories of type 0, 1 and 2 respectively.') }}
  • {{ _('Budget usage percentages are driven by the monthly budgets configured on those categories.') }}
  • {{ _('To change limits or rebalance your plan, use the Categories section; the home dashboard will refresh automatically based on your new configuration.') }}
