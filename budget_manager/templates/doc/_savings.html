{{ _('Savings') }}

{{ _('The Savings module helps you organize your savings into named envelopes, define goals and ratios, and keep them synchronized with your real account balance.') }}

{{ _('Savings overview') }}

{{ _('The main Savings page displays all savings as cards, along with the total saved amount and a donut chart summarizing the distribution.') }}

  • {{ _('Saving cards') }} – {{ _('each card shows the saving name and icon, its current amount, the percentage of the global balance it represents, and optionally its ratio and goal progress.') }}
  • {{ _('Goal progress bars') }} – {{ _('when a goal is defined, a horizontal bar shows how close the current amount is to the target, with a percentage label.') }}
  • {{ _('Actions on a saving') }} – {{ _('you can edit a saving to change its configuration or delete it entirely. Deletion is protected by a confirmation dialog and will remove the saving along with its historical snapshots; any remaining balance is transferred to Base. The Base saving is created with the database and cannot be deleted or renamed.') }}

{{ _('Adding and editing a saving') }}

{{ _('The saving forms share the same structure when adding or editing:') }}

  • {{ _('Name, note, color and icon') }} – {{ _('define the identity of the saving (what it is for) and make it easy to recognize in charts and cards.') }}
  • {{ _('Amount') }} – {{ _('the current amount can be expressed either as a percentage of the global balance (slider) or directly in euros; both inputs stay synchronized and a hidden field stores the canonical value.') }}
  • {{ _('Goal') }} – {{ _('an optional target amount. The application ensures that the saved amount never exceeds the goal and uses it to compute progress indicators and estimated completion dates in analytics.') }}
  • {{ _('Ratio for leftover distribution') }} – {{ _('a number between 0 and 1 that expresses how much of the monthly “leftover for savings” should go to this saving relative to others.') }} {{ _('Ratios are automatically normalized across all savings so that their sum remains equal to 1, with special handling for the “Base” saving, which acts as a buffer.') }}

{{ _('When you change the ratio of a saving, the system recalculates the other ratios to respect the global 1.0 sum while preserving proportions as much as possible.') }}

{{ _('Monthly distribution of savings') }}

{{ _('Monthly distribution is designed to transform the theoretical “remaining for savings” of a month into concrete allocations on individual savings.') }}

  • {{ _('Leftover for savings') }} – {{ _('a dedicated function computes, for any month and year, how much income remains once fixed and variable expenses linked to the “Base” saving (or no saving) are taken into account.') }}
  • {{ _('Source of distribution') }} – {{ _('the distribution process takes the leftover amount from the “Base” saving, ensuring that this buffer decreases by exactly what is being distributed (or by the available amount if it is smaller).') }}
  • {{ _('Distribution logic') }} – {{ _('if ratios are defined, the leftover is split proportionally according to these ratios. If not, the system falls back to a distribution based on current saving amounts or, when necessary, an equal distribution.') }} {{ _('Goals are always respected: no saving will be pushed above its goal; any extra is re-distributed to remaining eligible savings.') }}
  • {{ _('Manual trigger') }} – {{ _('the “Distribute Monthly” button on the Savings page calls this logic for the current (or previous) month, updates all savings and informs you about the amount that has been distributed.') }}

{{ _('Adjusting savings to the real balance') }}

{{ _('Over time, minor differences can appear between the sum of all savings and the actual account balance computed from transactions.') }} {{ _('The “Adjust Amounts” feature recalculates savings so that their total exactly matches the real balance.') }}

  • {{ _('Primary adjustment') }} – {{ _('the first pass tries to absorb the difference inside the “Base” saving when it exists, since it is the natural buffer for discrepancies.') }}
  • {{ _('Handling negative amounts') }} – {{ _('if some savings become negative after an adjustment, they are reset to zero and the deficit is redistributed proportionally across positive savings, never exceeding goals.') }}
  • {{ _('Final consistency check') }} – {{ _('after redistribution, the system performs a final pass to ensure that no saving exceeds its goal and that the total of all savings is as close as possible to the real balance.') }}

{{ _('Snapshots and history') }}

{{ _('The application can take snapshots of all savings at a given date, storing historical amounts for later analysis.') }}

  • {{ _('Automatic snapshots') }} – {{ _('analytics make sure that a snapshot exists for the current day before computing long‑term charts, so you always have a coherent time series.') }}
  • {{ _('Manual snapshots') }} – {{ _('the “Snapshot” button on the Savings page forces the creation of a snapshot for today if it does not already exist, and confirms how many entries were created.') }}
